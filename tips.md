# Open an App
- `Alt + F2` -> open a 1-line command launcher
- `launch <app>` -> launch app, hide terminal window, keep app running

## Scratch helpers
- `scratch push` -> hide terminal window
- `scratch pop` -> show last hidden 
- `scratch popall` -> show all hidden

# Shortcuts
- `~ + Tab` → list named directories

# Render .md
- `glow <file>`

---

# Terminal Tree view
* `lsd --tree --depth 2`

# Terminal splits
* `Ctrl + Shift + R / D` -> horizontal / vertical
* `Ctrl + Shift + E` -> close
* `Alt + Arrow keys` -> navigate
